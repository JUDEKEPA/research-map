About this workspace

The inventory includes every discovered file and directory under the selected project, including hidden files, backups and empty folders. Symlink targets are not traversed.

Choose Graph for the interactive map or Folders for the directory browser. Only one navigation view appears at a time. Open folders to descend. Files lists exact files; Figures shows only the selected analysis folder’s direct exports and groups PNG/PDF exports with the same filename stem. Formats remain individually reachable. Search and filters operate within the current folder; use Search whole folder to broaden the scope.

Analysis records use a general JSON structure: description, storage folders, code, data, figures, documents and relationships. Descriptions are imported from report contents and can be edited. Hover over a compact graph node to read its description. The graph follows direct parent/child folders. Navigation folders hide the inspector. Analysis folders expose their direct files and labelled code candidates. The file inventory remains a separate complete fallback.

Codex CLI uses your installed account configuration and sends the selected item's context, nearby report excerpts, and conversation to its configured provider. Portable sessions can write their private terminal folder and project metadata, with on-request approval for additional access. Local guide is a deterministic catalogue lookup. No analyses are executed.
